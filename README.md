### 아침 브리핑

시험 기간마다 시간표는 나이스, 과제는 e알리미, 공부 계획은 메모장, 일정은 캘린더에 흩어져 있어서 만들었습니다.

- 나이스 API에서 학사일정·시간표·급식을 받아 **내 학년·반·학과에 해당하는 것만** 보여 줍니다.
- 학교·학원·일정을 뺀 빈 시간에 *급한 과제 → 오늘 공부 계획 → 어제 못 한 것* 순서로 50분 공부 + 10분 휴식을 배치합니다.
- e알리미 가정통신문을 붙여 넣으면 글 속 날짜를 찾아 캘린더에 넣습니다.
- 회원가입(전국 학교 검색), 계정별 데이터 분리, 비밀번호 해시(PBKDF2)
- 개인 정보(시험 일정, 공부 계획, API 키)는 깃에 올라가지 않는 별도 파일로 분리했습니다.

### 강의 노트 AI

- 녹음을 줄여서(모노, 16kHz) Whisper로 `[분:초]` 대본을 만듭니다.
- AI 세 개가 각각 요약하고 서로 비교해 하나의 노트로 합칩니다. (다중 AI 교차 검증)
- 무료 API 한도에 걸리면 다음 AI로 자동으로 넘어갑니다.

## 대회 · 활동

### 국제로봇콘테스트(IRC) 2026 디지털트윈 부문 (2026.11)

FANUC ROBOGUIDE로 물류 자동화 셀을 만들고 로봇 프로그램을 짜는 대회입니다. 이틀 동안 빈 셀에서 시작해 4개 모듈을 완성해야 하고, 외부 프로그램을 가져갈 수 없어서 모든 것을 현장에서 처음부터 만들어야 합니다.

| 모듈 | 내용 |
|---|---|
| A | 셀 배치, 그리퍼 장착, User Frame·Tool Frame·Payload 설정, 그리퍼 동작 확인 |
| B | 입력 팔레트 → 컨베이어 → 패키지 적재 → 출력 팔레트로 이어지는 기본 물류 자동화 |
| C | 생산 코드에 따라 다른 제품을 만드는 유연 생산, 오류 처리(E01~E06) |
| D | 동작 최적화, HMI 상태 화면 |

**준비한 방법**

- 대회 3주 전부터 날짜·시간대별 연습 일정표를 만들었습니다. (약 98시간: 주말, 기능반 방과후, 쉬는 시간·점심, 집 저녁)
- 현장에서 처음부터 다시 만들어야 하니까, 작업을 13개 드릴로 쪼개서 목표 시간을 정하고 반복했습니다. 예: User Frame 1개 교시 5분, 그리퍼 장착 15분, 모듈 A 전체 2시간 30분
- 대회 I/O 번호, 오류 코드, 생산 코드를 PC 없이 볼 수 있는 암기 카드로 만들었습니다.
- 준비 상황을 정리한 중간 보고서를 작성했습니다.

**결과:** 15명 중 11위

기능경기대회 모바일로보틱스 종목을 준비하며 로봇을 **설계하고 제작**했습니다. 대회 전에 동아리가 해체되어 출전하지는 못했습니다.
